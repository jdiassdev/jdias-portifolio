# jdias-portifolio

> Vue 3 · Vite 6 · Tailwind CSS v4 · Vue Router v4

**Live:** https://jdiassdev.netlify.app

---

## setup

```bash
# git clone
git clone https://github.com/jdiassdev/jdias-portifolio.git
# entrar no repo
cd jdias-portifolio
# instalar dependencias
pnpm install
# rodar modo dev
pnpm dev
```

## scripts

```bash
pnpm dev      # dev server → localhost:5173
pnpm build    # build → ./dist
pnpm preview  # serve ./dist localmente
pnpm lint     # oxlint
```

## env

```env
VITE_GITHUB_URL=https://github.com/seu-usuario
```
